🎉 Actualización: Costo de Matrícula Automático

✅ IMPLEMENTACIÓN EXITOSA

Se ha agregado la funcionalidad para mostrar el costo de matrícula en los detalles del programa y autocompletar automáticamente el campo de pago.

📋 Cambios Realizados

1. Vista - inscripcion.php

Archivo: vistas/componentes/inscripcion.php
Cambio: Se agregó el campo "Costo Matrícula" en el panel de detalles del programa
<div class="col-md-6"> <p><strong>Costo Total:</strong> <span id="detalle-costo-total"></span></p> <p><strong>Costo Matrícula:</strong> <span id="detalle-costo-matricula"></span></p> <p><strong>Sede:</strong> <span id="detalle-sede"></span></p> ... </div>

2. JavaScript - programa.js

Archivo: vistas/recursos/assets/js/scripts/programa.js
Cambios:
  • Muestra el costo de matrícula en los detalles
  • Autocompleta el campo de pago matrícula
  • Limpia el campo al cambiar de grado académico o programa
// Mostrar y autocompletar costo de matrícula var costoMatricula = respuesta.CostoMatricula ? parseFloat(respuesta.CostoMatricula) : 0; $('#detalle-costo-matricula').text('Bs. ' + costoMatricula.toFixed(2)); // Autocompletar el campo de pago matrícula $('input[name="montoMatricula"]').val(costoMatricula.toFixed(2));

✨ Funcionalidades Implementadas

  • Visualización automática: Al seleccionar un programa, se muestra su costo de matrícula en los detalles
  • Autocompletado: El campo "PAGO MATRÍCULA" se llena automáticamente con el valor del costo de matrícula del programa
  • Limpieza automática: Al cambiar de grado académico o programa, el campo se limpia y actualiza
  • Formato de moneda: Los valores se muestran con formato boliviano (Bs. X,XXX.XX)
  • Validación de datos: Verifica que el campo exista antes de mostrarlo

🔄 Flujo de Funcionamiento

Paso 1: Seleccionar Grado Académico

Usuario selecciona: MAESTRÍA

→ Se cargan los programas de maestría

→ Campo de matrícula se limpia

Paso 2: Seleccionar Programa

Usuario selecciona: MESTRIA EN ORTODONCIA

→ Se cargan los detalles del programa:

  • Costo Total: Bs. 25,000.00
  • Costo Matrícula: Bs. 1,500.00
  • Duración: 24 meses
  • Módulos: 12
  • Sede: ORURO

Paso 3: Campo Autocompletado

Campo "PAGO MATRÍCULA" se llena automáticamente:

PAGO MATRÍCULA:

→ El usuario puede modificar el valor si es necesario
