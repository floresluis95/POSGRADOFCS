✅ Archivo Actualizado

Archivo: selectprograma.js

Se ha agregado la funcionalidad para mostrar el costo de matrícula y autocompletar el campo de pago.

📋 Instrucciones para Probar

  1. Haz clic en el botón "Ir a Inscripción" abajo
  2. Selecciona un GRADO ACADÉMICO (DIPLOMADO, MAESTRÍA o ESPECIALIDAD)
  3. Selecciona un PROGRAMA de la lista
  4. Verifica que se muestre:
    • ✓ Panel "Detalles del Programa"
    • ✓ Campo "Costo Total"
    • ✓ Campo "Costo Matrícula" (NUEVO)
    • ✓ Otros detalles (Sede, Fecha Inicio, etc.)
  5. Verifica que el campo "PAGO MATRÍCULA" se autocomplete con el valor del costo de matrícula

🔍 Qué Buscar en la Vista

  • Programa: [Nombre del programa]

💡 Comportamiento Esperado

  • Al seleccionar un programa, se muestra el panel de detalles
  • El Costo Matrícula aparece en color azul
  • El campo "PAGO MATRÍCULA" se llena automáticamente con el mismo valor
  • Si cambias de grado académico o programa, el campo se actualiza
  • Puedes modificar manualmente el valor del campo si es necesario

🐛 Si NO Funciona

Prueba lo siguiente:

  1. Limpia el caché del navegador:
    • Chrome/Edge: Ctrl + Shift + Delete
    • Firefox: Ctrl + Shift + Delete
  2. Recarga la página con forzar actualización:
    • Ctrl + F5 (Windows)
    • Cmd + Shift + R (Mac)
  3. Abre la Consola del Navegador:
    • F12 → Pestaña "Console"
    • Busca errores en rojo
    • Mira si hay mensajes de error en la consola
  4. Verifica que el archivo JS se cargue:
    • F12 → Pestaña "Network"
    • Recarga la página
    • Busca selectprograma.js
    • Debe aparecer con estado 200 (OK)
