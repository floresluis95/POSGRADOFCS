  • ListarInscripcionesModelo() - Lista todas las inscripciones
  • ObtenerInscripcionPorIdModelo() - Obtiene inscripción específica
  • ActualizarEstadoInscripcionModelo() - Actualiza estado
  • ObtenerInscripcionesPorEstudianteModelo() - Lista por estudiante

Controlador (MatriculaControladores)

  • RegistrarMatriculaControlador() - Procesa formulario
  • Validación completa de campos
  • Validación de imagen (tipo y tamaño)
  • Conversión de imagen a BLOB
  • Mensajes con SweetAlert

  • Validación del formulario en el cliente
  • Validación de tipo de archivo
  • Validación de tamaño (máx 5MB)
  • Vista previa de imagen

Sistema de Filtrado (programa.js)

📊 Estructura de la Tabla

Campo Tipo Descripción
idInscripcion INT(11) ID único (AUTO_INCREMENT)
EstudianteID INT(11) ID del estudiante
ProgramaID INT(11) ID del programa
costomatricula INT(11) Monto de matrícula
nvauchermatricula INT(11) Número de vaucher
FechaInscripcion DATE Fecha de inscripción
foto BLOB Imagen del comprobante
Estado VARCHAR(20) Estado (ACTIVO/INACTIVO)

⚠️ Validaciones Activas

  • Todos los campos son obligatorios
  • Estudiante debe estar activo
  • Programa debe estar activo
  • Monto debe ser mayor a 0
  • Imagen obligatoria (JPG, PNG, GIF, PDF)
  • Tamaño máximo de imagen: 5MB
  • No permite inscripciones duplicadas
  • Transacciones con ROLLBACK en caso de error
